1. Apakah MasjidTV?

MasjidTV ialah sistem paparan digital untuk masjid. Ia menunjukkan:

  • Waktu solat automatik (mengikut zon JAKIM — 60 zon pilihan)
  • Tarikh Hijrah & acara Islam automatik
  • Pengumuman gambar, video, dan teks berjalan (ticker)
  • Aliran langsung kamera atau YouTube
  • Kutipan tabung, logo masjid, tema warna

Anda hanya perlu mengemas kini kandungan di laman web admin — TV akan dikemas kini secara automatik dalam beberapa saat.

2. Langkah Mula (5 minit)

  1. Log masuk ke laman web admin (pautan diberikan oleh vendor/pasangan anda).
  2. Tetapkan profil masjid — nama, logo, alamat.
  3. Pilih zon JAKIM anda (contoh: "WLY01" untuk Kuala Lumpur).
  4. Tambah pengumuman pertama anda — taip teks atau muat naik gambar.
  5. Pasang di TV — lihat bahagian "Pasang TV / Paparan" di bawah.

Selesai! TV anda kini menunjukkan waktu solat dan pengumuman secara automatik.

3. Log Masuk Admin

  1. Buka pautan laman web admin di pelayar (Chrome / Edge / Firefox).
  2. Masukkan nama pengguna dan kata laluan yang diberikan.
  3. Klik "Log Masuk".

Untuk akaun superuser (pentadbir utama), anda akan diminta menukar PIN keselamatan pada log masuk pertama. Sila tukar kepada PIN yang mudah anda ingat tetapi sukar diteka.

4. Tetapkan Profil Masjid

  1. Klik "Profil Masjid" di menu kiri.
  2. Masukkan nama masjid (contoh: "Masjid Al-Hidayah").
  3. Muat naik logo masjid (gambar PNG/JPG, disyorkan bersaiz kecil).
  4. Pilih tema warna — ada tema gelap dan terang, atau warna tersendiri.
  5. Klik "Simpan".

Perubahan akan muncul di TV dalam beberapa saat.

5. Pilih Zon Waktu Solat

  1. Klik "Waktu Solat" di menu kiri.
  2. Pilih zon JAKIM anda dari senarai (60 zon seluruh Malaysia).
  3. Sistem akan automatik mengira waktu solat setiap hari — tiada perlu kemas kini manual.
  4. Acara Islam (tarikh penting) juga disegerakkan automatik dari JAKIM.

Waktu solat dikemas kini setiap hari. Jika tiada internet, waktu solat terakhir yang disimpan akan digunakan sehingga internet kembali.

6. Pengumuman & Ticker

Anda boleh membuat dua jenis pengumuman:

  • Gambar / Video — muat naik fail, ia akan dipaparkan sebagai slaid.
  • Teks berjalan (ticker) — ayat yang bergerak di bawah skrin (contoh: "Kuliah Maghrib malam ini di dewan utama").
  1. Klik "Pengumuman" di menu kiri.
  2. Klik "Tambah Pengumuman".
  3. Pilih jenis (gambar/video atau teks).
  4. Taip ayat atau muat naik fail.
  5. Klik "Simpan".

Anda boleh susun urutan pengumuman dengan menarik dan menurunkan (drag & drop).

7. Muat Naik Gambar / Video

  1. Klik "Kandungan & Media" di menu kiri.
  2. Klik "Muat Naik" dan pilih fail dari komputer anda.
  3. Fail yang disokong: gambar (PNG, JPG, WebP, GIF), video (MP4, WebM).
  4. Fail tersimpan di storan cloud selamat.

Saiz maksimum setiap fail: 10 MB. Untuk video besar, sila kecilkan saiz dahulu (guna HandBrake atau seumpamanya).

8. Pasang TV / Paparan

Ada tiga cara untuk memasang paparan di TV masjid:

Cara A: Mini PC Windows (digalakkan)

  1. Muat turun MasjidTV-Kiosk-Setup dari pautan yang diberikan.
  2. Pasang di mini PC yang disambung ke TV melalui HDMI.
  3. Buka aplikasi — ia akan muncul di TV sebagai paparan penuh.
  4. Lihat kod 6 angka di skrin TV.
  5. Di laman web admin, klik "TV & Paparan" → masukkan kod → klik "Pasang TV".
  6. TV kini dipasang! Ia akan mula paparan serta-merta.

Cara B: Android TV

  1. Pasang aplikasi MasjidTV dari fail APK di Android TV.
  2. Buka aplikasi — kod 6 angka akan dipaparkan.
  3. Masukkan kod di laman web admin seperti Cara A di atas.

Cara C: Pelayar Web (paling mudah, untuk ujian)

  1. Buka pelayar di TV / peranti yang ada.
  2. Pergi ke pautan paparan (format: https://[laman-web-anda]/display?key=[kunci]).
  3. Kunci paparan (display key) dijumpai di laman web admin → "TV & Paparan".

9. Pasang di Mini PC Windows (Terperinci)

Untuk pemasangan kekal di masjid, gunakan mini PC Windows dengan aplikasi Kiosk.

  1. Muat turun fail MasjidTV-Kiosk-Setup-x.y.z.exe.
  2. Klik dua kali fail untuk memasang.
  3. Jika Windows Smart App Control menyekat, pilih "Run anyway" (Run anyway) — ini selamat.
  4. Selepas pasang, aplikasi akan buka automatik dan muncul di TV.
  5. Aplikasi akan mulai automatik setiap kali mini PC dinyalakan (autostart).
  6. Lihat kod 6 angka di TV, masukkan di laman web admin untuk memasang.

Menu Tersembunyi (Ctrl+Shift+M)

Jika perlu semak status atau nyahpasang TV dari mini PC:

  1. Tekan kekunci Ctrl + Shift + M serentak di papan kekunci.
  2. Menu akan muncul dengan status perkahwinan, kamera, dan pilihan nyahpasang.
  3. Tekan Esc untuk tutup menu.

Kamera / OBS Virtual Camera

Jika anda guna OBS Studio untuk siaran langsung, aplikasi akan automatik kesan "OBS Virtual Camera" dan boleh dijadikan aliran (stream) di paparan.

10. Pasang di Android TV

  1. Muat turun fail APK MasjidTV.
  2. Pindahkan ke Android TV (guna pemacu USB atau pelayar fail).
  3. Buka fail APK di Android TV untuk memasang (benarkan "pasang dari sumber tidak diketahui" jika ditanya).
  4. Buka aplikasi — kod 6 angka akan muncul.
  5. Masukkan kod di laman web admin → "TV & Paparan" → "Pasang TV".

Android TV menyokong siaran langsung RTSP/RTMP melalui ExoPlayer. Tiada sokongan SSE (pantaian segera) — TV akan kemas kini setiap 10 saat.

11. Selesaikan Masalah Biasa

TV menunjukkan skrin "Tidak Berpasangan" / "Peranti Dinyahpasang"

TV perlu dipasang semula. Dapatkan kod 6 angka baharu di skrin TV, masukkan di laman web admin → "TV & Paparan".

TV tidak kemas kini selepas saya ubah sesuatu

Tunggu sehingga 10 saat. Jika masih tidak berubah, semak sambungan internet di TV/mini PC. Untuk mini PC, tekan Ctrl+Shift+M untuk semak status.

Waktu solat tidak betul

Semak zon JAKIM di "Waktu Solat" — pastikan zon yang betul untuk kawasan masjid anda. Jika masih salah, hubungi vendor.

Video tidak main di TV

Pastikan format video MP4 atau WebM. Jika fail terlalu besar, kecilkan saiz dahulu. Untuk mini PC, pastikan ffmpeg dibundel (pasang semula jika perlu).

Tidak boleh log masuk admin

Selepas 5 cubaan salah, akaun dikunci selama 15 minit. Tunggu dan cuba semula. Jika lupa kata laluan, hubungi superuser atau vendor.

Skrim hitam / kosong di TV

Untuk mini PC: mulakan semula mini PC. Aplikasi akan buka automatik. Untuk pelayar web: muat semula halaman (tekan F5 atau Ctrl+R).

Tiada sambungan internet di mini PC

Paparan akan terus menunjukkan kandungan terakhir yang disimpan (offline). Apabila internet kembali, kandungan akan kemas kini automatik.

12. Soalan Lazim

Adakah saya perlu bayar yuran bulanan?

Lesen MasjidTV adalah abadi (perpetual) — bayar sekali, guna selamanya. Tiada yuran bulanan. Tempoh percubaan 14 hari disediakan untuk masjid baru.

Bolehkah saya guna tanpa internet?

Ya. Selepas pemasangan pertama, TV/mini PC akan terus papar kandungan walaupun tanpa internet. Anda hanya perlu internet untuk mengemas kini kandungan dari laman web admin.

Berapa banyak TV boleh dipasang?

Tiada had. Setiap TV dipasang dengan kod unik. Anda boleh namakan setiap TV (contoh: "Dewan Utama", "Solat Perempuan").

Adakah data saya selamat?

Ya. Data disimpan di pangkalan data cloud selamat (Turso) dengan penyulitan. Setiap masjid (tenant) diasingkan — masjid lain tidak boleh lihat data anda. Sandaran automatik dibuat setiap hari.

Bolehkah saya guna kamera langsung?

Ya. Sokongan RTSP, RTMP, ONVIF (kamera IP), OBS Virtual Camera, dan YouTube Live. Untuk mini PC, kamera diproses secara lokal melalui ffmpeg — tidak membebankan internet.

Bagaimana jika saya perlukan bantuan?

Hubungi vendor/pasangan anda yang memasang sistem. Untuk isu teknikal, rujuk README teknikal di repositori GitHub.
