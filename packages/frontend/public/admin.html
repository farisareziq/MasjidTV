👋 Welcome! Complete these steps to get your screen running:

    Notes

    • Point any screen on the network to — and open it fullscreen (Edge kiosk handles this automatically on the mini PC).
    • ⚠️ The default admin password file still exists at server/data/ADMIN_PASSWORD.txt. Change the password in Settings and the file is removed.
    • Prayer times and hijri date come from the official JAKIM e-Solat API (selected zone), with automatic offline calculation fallback.
    • 📅 Islamic events auto-synced from JAKIM takwim.
    • 🔊 Adhan/Iqamah audio is configured — the screen will call at prayer times.
    • 📡 — live stream(s) configured. RTSP/RTMP/ONVIF need ffmpeg on the mini PC.

    Checking ffmpeg…

    RTSP, RTMP and ONVIF streams are converted to HLS by ffmpeg on this machine and shown in the slideshow. YouTube accepts a normal or live video URL. WebRTC uses a custom embed URL (e.g. your WebRTC gateway page).
